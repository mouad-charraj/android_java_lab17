



# Lab Broadcast Receivers - CHARRAJ Mouad

Ce projet illustre l'utilisation des Broadcast Receivers sous Android (statiques et dynamiques).

## Auteur
Realise par CHARRAJ Mouad aka ZERO-XR7

## Fonctionnalites
- Receiver Dynamique : Capte le changement du mode avion.
- Receiver Statique : Capte le demarrage du telephone (BOOT_COMPLETED).
- Custom Broadcast : Envoi et reception d'un evenement personnalise.
